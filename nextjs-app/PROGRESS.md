## 🚀 Как запустить проект

### Первый раз:
```bash
cd nextjs-app
npm install
npm run db:push
npm run seed
npm run dev
```

### При каждом запуске:
```bash
cd nextjs-app
npm run dev
```

Приложение будет доступно на `http://localhost:3000` (или `http://localhost:3001` если порт занят).

## 📁 Ключевые файлы

- `prisma/schema.prisma` - схема БД
- `prisma/seed.ts` - скрипт для заполнения БД
- `src/app/layout.tsx` - главный layout
- `src/app/page.tsx` - главная страница со списком продуктов
- `src/app/product/[id]/page.tsx` - страница отдельного продукта
- `src/app/api/products/route.ts` - API для получения всех продуктов
- `src/app/api/products/[id]/route.ts` - API для получения конкретного продукта
- `src/app/api/products/[id]/reviews/route.ts` - API для отзывов
- `src/components/ui/` - UI компоненты
- `src/styles/globals.css` - глобальные стили
